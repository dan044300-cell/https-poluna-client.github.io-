# Poluna Client Website

Official website for Poluna Client - Premium Minecraft Cheat

## Deployment

This website is deployed on GitHub Pages at: https://poluna-client.github.io/

## Setup Instructions

1. Install Git from https://git-scm.com/
2. Create a GitHub account at https://github.com
3. Create a new repository named `poluna-client.github.io`
4. Clone this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/poluna-client.github.io.git
   ```
5. Copy all files from the `website` folder to the cloned repository
6. Push to GitHub:
   ```bash
   git add .
   git commit -m "Initial commit"
   git push origin main
   ```
7. Your site will be live at `https://poluna-client.github.io/`
